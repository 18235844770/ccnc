# 碳交易理财推广系统

**开发文档 / 技术设计说明**

------

## 1. 文档概述

### 1.1 文档目的

- 明确系统技术架构
- 明确模块拆分与职责
- 明确核心业务实现方式
- 降低开发理解偏差与返工风险

------

### 1.2 系统组成

```
H5 用户端（浏览器）
    ↓
后端 API 服务
    ↓
数据库 / 缓存 / 消息队列
    ↓
管理后台（Web）
```

------

## 2. 技术架构设计

### 2.1 技术选型建议

| 层级     | 技术                       |
| -------- | -------------------------- |
| H5前端   | Vue3 / React               |
| 管理后台 | Vue + Element Plus         |
| 后端     | Java Spring Boot / Node.js |
| 数据库   | MySQL 8.x                  |
| 缓存     | Redis                      |
| 消息队列 | RabbitMQ / Kafka           |
| 文件存储 | OSS / COS                  |
| 部署     | Docker + 云服务器          |

------

### 2.2 架构原则

- 前后端分离
- 核心业务服务化
- 分润计算异步化
- 推广关系不可逆

------

### 4.2 关键业务说明

- 注册时写入 `parent_user_id`

- 推广关系写入后不可修改（除管理员）

## 6. 订单与投资模块

### 6.1 订单状态流转

```
待支付 → 已支付 → 生效中 → 已到期 → 已结算
```

------

### 6.2 投资规则

- 支付成功即生成订单
- 到期由定时任务结算
- 卖出/退款需反向处理分润

------

## 7. 推广模块（核心）

### 7.1 推广关系模型

```
用户A
 └─ 用户B（1级）
     └─ 用户C（2级）
         └─ 用户D（3级）
```

------

### 7.2 推广关系实现方案（推荐）

**字段冗余方案：**

- `parent_id`
- `level`
- `path`（如：1/3/8/20）

> 优点：
>
> - 查询快
> - 便于统计
> - 易于限制 5 级

------

### 7.3 推广绑定逻辑（伪流程）

```
注册 → 判断是否携带推广参数
→ 查询父级层级
→ 若 ≥5 则绑定第5级
→ 写入推广关系
```

------

## 8. 分润与收益模块

### 8.1 分润计算方式

- 基于订单异步计算
- 消息队列处理
- 防止阻塞交易

------

### 8.2 分润流程

```
订单完成
→ MQ发送事件
→ 分润服务计算
→ 生成分润记录
→ 等待结算
```

------

### 8.3 分润记录状态

- 待结算
- 已结算
- 已发放
- 已冻结
- 已作废
