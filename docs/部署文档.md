# CCNC 完整部署文档（生产环境）

本文档适用于当前仓库（pnpm monorepo）：
- 后端：`service`（NestJS + Prisma）
- 管理后台：`admin-web`（Vue3 + Vite）
- 用户端：`h5`（uni-app H5）
- 数据库：PostgreSQL + Redis（Docker）

## 1. 部署架构建议

- 应用服务器：1 台 Linux（建议 Ubuntu 22.04 LTS，2C4G 起）
- 反向代理：Nginx（80/443）
- 后端进程：PM2 托管 `service/dist/main.js`
- 静态站点：
  - 管理后台发布到 `/var/www/ccnc/admin`
  - H5 发布到 `/var/www/ccnc/h5`
- 数据层：Docker 容器运行 PostgreSQL + Redis

## 7. 构建并发布前端（admin-web + h5）

## 7.1 管理后台 `admin-web`

生产建议新增 `admin-web/.env.production`：

```env
VITE_APP_BASE_API=/api/v1
```

构建并发布：

```bash
cd /opt/CCNC
pnpm build:admin
mkdir -p /var/www/ccnc/admin
cp -r admin-web/dist/* /var/www/ccnc/admin/
```

### 7.2 H5 `h5`

建议使用生产变量文件（推荐 `h5/.env.production`）：

```env
VITE_API_HOST=https://api.your-domain.com
```

构建：

```bash
cd /opt/CCNC
pnpm --filter uni-preset-vue build:h5
```

> uni-app H5 构建产物常见目录为 `h5/dist/build/h5`。  
> 如果目录不同，请在 `h5` 目录执行一次 `ls` 确认最终产物路径。

发布：

```bash
mkdir -p /var/www/ccnc/h5
cp -r /opt/CCNC/h5/dist/build/h5/* /var/www/ccnc/h5/
```

## 8. Nginx 配置（域名反代 + 静态托管）

示例：三域名拆分
- `api.your-domain.com` -> 后端 3000
- `admin.your-domain.com` -> 管理后台静态站
- `h5.your-domain.com` -> H5 静态站

创建配置 `/etc/nginx/sites-available/ccnc.conf`：

```nginx
server {
    listen 80;
    server_name api.your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

server {
    listen 80;
    server_name admin.your-domain.com;
    root /var/www/ccnc/admin;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}

server {
    listen 80;
    server_name h5.your-domain.com;
    root /var/www/ccnc/h5;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

启用配置：

```bash
ln -s /etc/nginx/sites-available/ccnc.conf /etc/nginx/sites-enabled/ccnc.conf
nginx -t
systemctl reload nginx
```

```bash

```

## 12. 常见问题排查

- 后端起不来：`pm2 logs ccnc-service --lines 200`
- 数据库连不上：`docker logs ccnc-postgres --tail 200`
- Redis 连不上：`docker logs ccnc-redis --tail 200`
- 502 错误：确认 `service` 正常监听 `3000` 且 Nginx `proxy_pass` 正确
- 跨域报错：检查 `service/.env` 中 `CORS_ORIGINS` 是否包含线上域名

## 13. 安全建议（生产必做）

- 立即修改默认数据库密码、JWT 密钥
- 服务器只开放 `22/80/443`，数据库端口不要暴露公网
- Nginx 配置请求大小与限流（可按需扩展）
- 定期备份 PostgreSQL（至少每日全量）
- 开启日志轮转与监控告警（CPU、内存、磁盘、进程存活）
