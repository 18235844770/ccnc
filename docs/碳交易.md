#  理财推广系统

**产品规划文档（PRD）**

## 1. 项目背景

### 1.1 项目目标

开发一套 **H5 网页端理财产品推广系统**，用于推广公司碳交易类理财产品，实现：

- 理财产品展示与买入/卖出
- 多级推广裂变（最多 5 级）
- 推广佣金自动结算
- 管理端统一配置、监控、风控

### 1.2 核心价值

- 低成本获客（社交裂变）
- 提升用户留存与复购
- 构建长期推广网络
- 数据可视化，精细化运营

------

## 2. 产品定位

| 维度     | 说明                                  |
| -------- | ------------------------------------- |
| 产品形态 | H5 网页端 + 管理后台                  |
| 用户类型 | 普通投资用户 / 推广用户 / 管理员      |
| 理财类型 | 碳交易相关理财产品（固定收益/周期型） |
| 推广机制 | 多级分润（≤5级）                      |
| 访问方式 | 微信 / 浏览器 / 分享链接              |

------

## 3. 用户角色定义

### 3.1 普通用户

- 浏览公司信息
- 购买理财产品
- 查看收益
- 可选择成为推广用户

### 3.2 推广用户（上线）

- 分享推广链接
- 发展下线（≤5级）
- 获得下线购买分成
- 查看推广收益

### 3.3 管理员

- 产品配置
- 分润规则配置
- 用户与资金管理
- 风控与数据统计

------

# 4. 业务规则说明

> 本章节用于明确系统中**推广关系、分润逻辑、用户身份、边界条件、异常处理规则**，是整个产品的核心约束层。

------

## 4.1 推广关系规则

### 4.1.1 推广关系定义

- 推广关系为 **单向绑定**
- 每个用户 **仅允许有 1 个直接上线**
- 推广关系一经绑定：
  - 不允许用户自行更换
  - 不允许重复绑定
  - 仅管理员在极特殊情况下可调整（需日志）

------

### 4.1.2 推广绑定时机

推广关系仅在以下场景成立：

| 场景                       | 是否绑定推广关系 |
| -------------------------- | ---------------- |
| 通过推广链接首次注册       | ✅ 是             |
| 通过推广二维码注册         | ✅ 是             |
| 普通注册（无推广参数）     | ❌ 否             |
| 已注册用户再次点击推广链接 | ❌ 否             |

> **原则：推广关系只认“首次注册来源”**

------

### 4.1.3 推广层级结构

- 推广关系采用 **树形结构**
- 层级自上而下依次为：
  - 一级下线
  - 二级下线
  - 三级下线
  - 四级下线
  - 五级下线

------

### 4.1.4 最大推广层级限制

- 系统允许的最大推广深度：**5 级**
- 当用户层级 = 第 5 级时：
  - ❌ 不可再发展下线
  - ❌ 推广链接失效
  - ❌ 推广二维码不可用
  - ✅ 仍可正常购买理财产品
  - ✅ 仍可获得自身投资收益

------

### 4.1.5 超层级处理规则

当新用户通过推广链路注册，但推广深度已超过 5 级时：

**处理策略（推荐）**

- 新用户注册成功
- 推广关系：
  - 绑定到 **第 5 级用户**
  - 不再向上继续计算推广关系
- 推广收益：
  - 超出部分 **不产生任何分润**

> 该策略用于防止“无限裂变”，降低法律与资金风险

------

## 4.2 推广身份与资格规则

### 4.2.1 推广用户定义

满足以下任一条件的用户，视为推广用户：

- 已成功绑定下线
- 或主动进入推广中心生成推广链接

------

### 4.2.2 推广资格限制（可配置）

后台可配置以下限制条件：

| 条件         | 示例     |
| ------------ | -------- |
| 最低投资金额 | ≥1000 元 |
| 实名认证     | 必须完成 |
| 风险提示确认 | 必须勾选 |
| 推广协议     | 必须同意 |

------

## 4.3 推广分润规则（核心）

### 4.3.1 分润触发条件

推广分润仅在以下条件全部满足时触发：

1. 下线成功购买理财产品
2. 订单状态为「已支付」
3. 产品状态为「正常生效」
4. 未发生退款或撤销

------

### 4.3.2 分润层级规则

- 分润最多向上计算 **5 级**
- 每一级分润比例 **独立配置**
- 各级分润互不影响

**示例配置：**

| 推广层级 | 分润比例 |
| -------- | -------- |
| 一级     | 10%      |
| 二级     | 5%       |
| 三级     | 3%       |
| 四级     | 2%       |
| 五级     | 1%       |

------

### 4.3.3 分润计算基数

后台支持以下分润计算模式（二选一）：

1️⃣ **按投资金额分润**

```
分润金额 = 投资金额 × 分润比例
```

2️⃣ **按实际收益分润（推荐）**

```
分润金额 = 用户实际收益 × 分润比例
```

> 出于合规考虑，**更推荐按收益分润**，避免“拉人头返现”风险

------

### 4.3.4 分润结算时机

支持多种结算策略（后台配置）：

| 模式               | 说明               |
| ------------------ | ------------------ |
| 到期结算           | 理财到期后统一结算 |
| 分期结算           | 按收益周期分批结算 |
| 实时记录，延迟发放 | 记录即时，到账延迟 |

------

### 4.3.5 分润状态流转

```
待结算 → 已结算 → 已发放 → 已提现
```

异常状态：

- 已冻结（风控）
- 已作废（退款/违规）

------

## 4.4 推广收益归属规则

### 4.4.1 归属原则

- 分润收益 **只归属于推广上线**
- 不可转赠
- 不可拆分
- 不可提前支取（未结算部分）

------

### 4.4.2 下线退款处理

若下线发生退款或撤销：

| 状态         | 处理方式         |
| ------------ | ---------------- |
| 未结算       | 分润直接作废     |
| 已结算未发放 | 冻结并冲正       |
| 已发放       | 计入负收益或扣回 |

------

## 4.5 推广异常与风控规则

### 4.5.1 异常推广行为

系统需识别以下行为：

- 同设备多账号注册
- 短时间内大量下线注册
- 自买自卖（同人多账号）
- 下线集中在单一IP

------

### 4.5.2 风控处理措施

| 风控等级 | 措施            |
| -------- | --------------- |
| 低风险   | 警告提示        |
| 中风险   | 冻结分润        |
| 高风险   | 封禁账号 + 清算 |

------

## 4.6 推广关系调整规则（管理端）

### 4.6.1 允许调整的情况

- 系统异常绑定
- 明确用户投诉
- 合规或司法要求

------

### 4.6.2 调整约束

- 已产生的历史分润 **不回溯**
- 调整操作必须：
  - 记录操作人
  - 记录调整原因
  - 记录时间

------

## 4.7 业务边界声明（合规重点）

- 推广收益定义为：

  > **“市场推广奖励”**

- 不承诺收益

- 不保证下线数量

- 不保证分润金额

- 推广与投资行为 **完全自愿**

## 6. 核心业务流程

### 6.1 推广注册流程

```
推广链接访问
→ 注册账号
→ 自动绑定上线
→ 校验推广层级（≤5）
→ 注册完成
```

### 6.2 投资分润流程

```
下线购买理财
→ 订单确认
→ 按层级计算分润
→ 分润记录生成
→ 到期结算
```

------

## 7. 非功能性需求

### 7.1 安全

- 防刷机制
- 防重复注册
- 推广关系不可随意更改
- 操作日志记录

### 7.2 性能

- 支持高并发访问
- 分润计算异步化
- 数据缓存机制

### 7.3 合规建议（重要）

> **碳交易 + 理财 + 多级分润存在合规风险**

- 避免“保本保收益”描述
- 明确风险提示
- 推广分成描述为“推广奖励”
- 层级限制明确（≤5级）
